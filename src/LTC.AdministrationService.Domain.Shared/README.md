# LTC.AdministrationService.Domain.Shared

## Purpose

Holds shared constants, localization resources, enums, and cross-layer domain contracts.

## Responsibilities

- Define global constants such as schema and connection name.
- Provide localization resource declarations.
- Provide permission and feature names used across layers.

## Key Files

- `AdministrationServiceDomainSharedModule.cs`
- `AdministrationServiceConsts.cs`
- `Localization/*`

## Notes

This project should have zero runtime infrastructure dependencies.
